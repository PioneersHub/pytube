# LinkedIn Posting Pipeline

Post conference video releases to LinkedIn using the [influent](https://github.com/PioneersHub/influent) library.

## Overview

This module integrates with influent to automate LinkedIn posting for conference videos. It:

1. Reads release records (generated by `text_generation` module)
2. Formats LinkedIn posts from AI-generated content
3. Creates influent-compatible YAML files
4. Publishes posts via influent CLI

## Prerequisites

### 1. Release Records

Release records must exist with AI-generated content:

```bash
# Generate release records first
python -m src.pipeline.text_generation.build_release_records --all
```

### 2. Configure influent

Set up LinkedIn credentials in `config_local.yaml`:

```yaml
linkedin:
  organization_name: "your-org-name"
  influent_path: ""  # Optional: custom path for influent data
```

### 3. Authenticate with LinkedIn

```bash
# Run influent authentication
influent --organization your-org-name auth
```

This opens a browser for LinkedIn OAuth authentication.

## Configuration

### Post Template

Customize the LinkedIn post template in `config.yaml`:

```yaml
linkedin:
  post_template: |
    ⭐️ New video release 📺

    {{ title }}

    {{ teaser_text }}

    📺 Watch on YouTube: {{ youtube_url }}

    {{ social_text }}

    {% if hashtags %}{{ hashtags }}{% endif %}
```

Available template variables:
- `{{ title }}` - Video title
- `{{ teaser_text }}` - One-sentence teaser (AI-generated)
- `{{ social_text }}` - Social media text (AI-generated)
- `{{ youtube_url }}` - Full YouTube URL
- `{{ hashtags }}` - Auto-generated hashtags

### Hashtags

Configure hashtags in `config.yaml`:

```yaml
linkedin:
  hashtags:
    enabled: true
    default: ["Python", "PyConDE", "PyData"]
    track_map:
      pydata: ["DataScience", "MachineLearning", "AI"]
      pycon: ["PythonDev", "SoftwareEngineering", "Programming"]
```

Hashtags are added based on:
1. Default hashtags (always included)
2. Track/channel-specific hashtags (from YouTube channel)

## Usage

### Step 1: Prepare Posts

Generate influent YAML files from release records:

```bash
# Prepare all posts
python -m src.pipeline.linkedin.prepare_posts --all

# Prepare specific sessions
python -m src.pipeline.linkedin.prepare_posts LRUKZQ 3CYZUH

# Force regeneration
python -m src.pipeline.linkedin.prepare_posts --all --force

# Limit for testing
python -m src.pipeline.linkedin.prepare_posts --all --limit 5
```

This creates:
- `{work_dir}/{event}/linkedin_posts/posts/*.yaml` - Influent YAML files
- `{work_dir}/{event}/linkedin_posts/metadata/*.json` - Metadata tracking

### Step 2: Publish Posts

Post to LinkedIn via influent CLI:

```bash
# Publish all prepared posts
python -m src.pipeline.linkedin.publish_posts --all

# Publish specific posts
python -m src.pipeline.linkedin.publish_posts LRUKZQ.yaml

# Dry run (validate without posting)
python -m src.pipeline.linkedin.publish_posts --all --dry-run

# Limit number of posts
python -m src.pipeline.linkedin.publish_posts --all --limit 5
```

Published files are moved to `linkedin_posts/published/`.

## Directory Structure

```
{work_dir}/{event}/linkedin_posts/
├── posts/           # Prepared YAML files (ready to post)
├── published/       # Published YAML files (moved after posting)
├── images/          # Images for posts (future feature)
└── metadata/        # Post metadata and tracking
```

## Workflow Integration

### Complete Pipeline

```bash
# 1. Fetch Pretalx records
python -m src.pipeline.pretalx.fetch_records

# 2. Generate AI summaries and release records
python -m src.pipeline.text_generation.build_release_records --all

# 3. Prepare YouTube metadata
python -m src.pipeline.youtube.prepare_metadata --all

# 4. Upload to YouTube (manual or via API)

# 5. Prepare LinkedIn posts
python -m src.pipeline.linkedin.prepare_posts --all

# 6. Publish to LinkedIn
python -m src.pipeline.linkedin.publish_posts --all
```

### Automated Posting

For automated posting after YouTube video release:

```python
# In your video release workflow
from pipeline.linkedin.prepare_posts import LinkedInPostPreparer

preparer = LinkedInPostPreparer()
preparer.prepare_post(pretalx_id="LRUKZQ")
```

## Troubleshooting

### Authentication Issues

```bash
# Re-authenticate with LinkedIn
influent --organization your-org-name auth

# Verify authentication
influent --organization your-org-name verify-auth
```

### Missing Release Records

```
Error: release_record_not_found
```

**Solution**: Generate release records first:
```bash
python -m src.pipeline.text_generation.build_release_records --all
```

### YouTube ID Not Found

```
Error: youtube_id_not_found
```

**Solution**: Ensure YouTube metadata exists in release records:
```bash
python -m src.pipeline.youtube.prepare_metadata --all
```

### Configuration Not Found

```
Error: linkedin configuration not found in config
```

**Solution**: Add LinkedIn configuration to `config_local.yaml`:
```yaml
linkedin:
  organization_name: "your-org-name"
```
