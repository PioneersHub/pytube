# Pretalx-YouTube Mapping Pipeline Module

Maps Pretalx session IDs to YouTube video IDs by extracting codes from uploaded video titles.

## Overview

This module creates the critical link between conference session data (from Pretalx) and uploaded videos (on YouTube). It extracts Pretalx session codes from YouTube video titles and validates the mappings against conference records.

## Key Features

- **Simple code extraction**: Extracts first 6 characters from video titles
- **Multi-channel support**: Handles multiple YouTube channels (PyCon, PyData, etc.)
- **Validation**: Checks do_not_record flags, channel assignments, missing sessions
- **Warning reports**: Generates detailed reports for validation issues
- **Pagination handling**: Fetches all videos from playlists automatically

## Prerequisites

### Required Files

1. **Pretalx Records**: `.work/{event}/pretalx_records/{id}.json`
   - Session data from conference system
   - Generated by: `python -m src.pipeline.pretalx.fetch_records`

2. **YouTube OAuth Credentials**: `.secrets/client_secrets.json`
   - OAuth2 client secrets from Google Cloud Console
   - First run will open browser for authentication
   - Token saved to `.secrets/youtube_token.json`

3. **Uploaded Videos**: Videos must be uploaded to YouTube
   - Filename format: `{6-CHAR-CODE}-title.mp4`
   - Added to configured playlist (for each channel)
   - Example: `3WLDMQ-Talk_About_Python.mp4`

4. **Channel Assignments** (Optional): `video_dir/tracks_map.json`
   - Maps session codes to channels
   - Generated by video organization step
   - Used for validation warnings

### Configuration

In `config_local.yaml`:

```yaml
pretalx:
  event_slug: "berlin2025"

youtube:
  client_secrets_file: ".secrets/client_secrets.json"
  channels:
    pydata:
      id: "UCOjD18EJYcsBog4IozkF_7w"
      playlist_id: "PLGVZCDnMOq0qKhzuzHGHiSAJRwKnlCIeS"
    pyconde:
      id: "UCji5VWDkGzuRenyRQZ9OpFQ"
      playlist_id: "PLHd2BPBhxqRK4cSON6xH100Der5nc8yWq"

dirs:
  work_dir: "./_tmp"
  video_dir: "/path/to/videos"  # Optional, for channel assignment validation
```

## Usage

### Step 1: Fetch YouTube Playlist Data

Fetch all videos from configured YouTube playlists:

```bash
# Fetch all channel playlists
python -m src.pipeline.pretalx_youtube_map.fetch_playlists
```

This will:
1. Authenticate with YouTube API (OAuth2)
2. For each configured channel:
   - Fetch all videos from the playlist
   - Handle pagination automatically
   - Save to `.work/{event}/pretalx_youtube_map/playlist_{channel}.json`
3. Save summary with total counts

**Output**: `playlist_pydata.json`, `playlist_pyconde.json`, etc.

### Step 2: Create Mapping

Create the Pretalx ID → YouTube ID mapping:

```bash
# Map all channels
python -m src.pipeline.pretalx_youtube_map.create_mapping

# Map specific channel only
python -m src.pipeline.pretalx_youtube_map.create_mapping --channel pydata
```

This will:
1. Load Pretalx session records
2. Load channel assignments (if available)
3. Load playlist data for each channel
4. For each video:
   - Extract Pretalx code (first 6 chars of title)
   - Validate against session data
   - Check do_not_record flag
   - Check channel assignment
5. Save mapping + warnings

**Output**:
- `mapping.json` - Main mapping dictionary
- `warnings.yaml` - Validation issues

## How It Works

### Code Extraction

Videos must be uploaded with filenames starting with the 6-character Pretalx session code:

```
Filename on disk:  3WLDMQ-Talk_About_Python.mp4
↓ (uploaded to YouTube)
YouTube title:     3WLDMQ-Talk_About_Python
↓ (extract first 6 chars)
Pretalx ID:        3WLDMQ
```

### Validation Checks

Each video mapping goes through validation:

1. **Session Exists**: Code must match a session in Pretalx records
   - Warning type: `missing_session`
   - Action: Skip video

2. **do_not_record Flag**: Session must not have `do_not_record=True`
   - Warning type: `do_not_record`
   - Action: Skip video

3. **Channel Assignment**: Check if video is in correct channel
   - Warning type: `channel_mismatch`
   - Action: Map video but log warning

4. **no_publishing Channel**: Session not assigned to "no_publishing"
   - Warning type: `no_publishing`
   - Action: Skip video

### Output Format

**mapping.json**:
```json
{
  "event_slug": "berlin2025",
  "created_at": "2025-10-29T23:45:00Z",
  "total_videos": 54,
  "mapped_videos": 48,
  "warnings_count": 6,
  "mappings": {
    "3WLDMQ": "--WDDsBCU4w",
    "BAASYV": "1LZqimczFKw",
    "TQN98D": "37S0ZDpJpc4"
  },
  "channels_processed": ["pydata", "pyconde"]
}
```

**warnings.yaml**:
```yaml
event_slug: berlin2025
created_at: 2025-10-29T23:45:00Z
warnings_count: 6
warnings:
  - pretalx_id: ABCD12
    youtube_id: xyz123
    video_title: "ABCD12 Missing Session"
    channel: pydata
    warning_type: missing_session
    message: "Pretalx session ABCD12 not found in records"

  - pretalx_id: WXYZ34
    youtube_id: abc456
    video_title: "WXYZ34 Do Not Record"
    channel: pyconde
    warning_type: do_not_record
    message: "Session WXYZ34 has do_not_record=True"
```

```bash
# 1. Ensure Pretalx records exist
ls .work/berlin2025/pretalx_records/
# Should show: 3WLDMQ.json, BAASYV.json, etc.

# 2. Videos have been uploaded to YouTube

python -m src.pipeline.pretalx_youtube_map.fetch_playlists

```

## Troubleshooting

### No videos found in playlist
- Verify playlist_id in config is correct
- Check that videos have been added to the playlist
- Ensure OAuth authentication succeeded

### Authentication failed
- Check `.secrets/client_secrets.json` exists
- Verify OAuth2 client is configured in Google Cloud Console
- Delete `.secrets/youtube_token.json` and re-authenticate

### missing_session warnings
- Video filename may have incorrect Pretalx code
- Check if session exists in Pretalx records:
  ```bash
  ls .work/berlin2025/pretalx_records/ABCD12.json
  ```
- Video may have been uploaded with wrong filename

### do_not_record warnings
- Session has `do_not_record=True` in Pretalx
- Either:
  - Remove video from YouTube
  - Fix flag in Pretalx and re-fetch records
  - Override by manually editing record (not recommended)

### channel_mismatch warnings
- Video is in wrong channel's playlist
- Check channel assignment:
  ```bash
  cat video_dir/tracks_map.json | grep ABCD12
  ```
- Move video to correct channel's playlist in YouTube Studio

## Integration with Pipeline

This module integrates with:

**Input from:**
- `pretalx.fetch_records` - Session data

**Used by:**
- `youtube.prepare_metadata` - Looks up YouTube IDs for metadata updates
- `youtube.send_updates` - Uses mapping to update correct videos
- Publishing/notification steps - Identifies which videos to process

## Module Components

### `fetch_playlists.py`
- Fetches playlist data from YouTube API
- Handles OAuth2 authentication
- Manages pagination
- Saves playlist data per channel

### `create_mapping.py`
- Loads Pretalx records and playlist data
- Extracts codes from video titles
- Validates against session data
- Creates mapping dictionary
- Generates warnings for issues

### `models.py`
- `PlaylistVideo`: YouTube playlist video data
- `VideoMapping`: Single mapping entry
- `ValidationWarning`: Validation issue
- `MappingResult`: Complete mapping with metadata
